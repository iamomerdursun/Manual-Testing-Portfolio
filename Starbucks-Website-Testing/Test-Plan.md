# Starbucks Website – Test Plan

## 1. Project Overview

This project aims to evaluate the functionality and usability of the Starbucks Turkey website through manual testing.

## 2. Test Objectives

- Verify website functionality.
- Identify software defects.
- Validate navigation and user interactions.
- Evaluate form validations.
- Check responsive behavior.

## 3. Test Scope

- Homepage
- Menu
- Membership
- Store Locator
- General Usability

## 4. Test Approach

Black Box Testing

## 5. Test Environment

- Operating System: Windows 10/11
- Browser: Google Chrome
- Platform: Desktop

## 6. Test Types

- Functional Testing
- Negative Testing
- UI Testing
- Regression Testing
- Usability Testing

## 7. Entry Criteria

Website is accessible and test environment is ready.

## 8. Exit Criteria

All planned test cases have been executed and results documented.

## 9. Limitations

Only publicly accessible functionality will be tested. No unauthorized transactions or real account creation will be performed.
